
# Ziblo
![Logo](https://ziblo.world/assets/img/horizontal-logo.png)
Ziblo is a playful and engaging language app made just for kids! Every word comes to life with bright pictures, clear pronunciation, and fun real-world sounds — like a frog croaking or a train whooshing by. It's not just learning, it’s exploring!

Kids can tap on images to hear how each word is said and, for many, hear what the object actually sounds like too. Whether it’s animals, colors, food, or everyday objects, Ziblo helps children build their vocabulary in a natural and joyful way.

Perfect for young learners, Ziblo turns screen time into learning time — fun, interactive, and full of discovery.

## Features

- Vue 3 – reactive frontend framework  
- Quasar Framework – UI components & layout

## Install the dependencies
```bash
yarn
# or
npm install
```

### Start the app in development mode (hot-code reloading, error reporting, etc.)
```bash
quasar dev
```


### Lint the files
```bash
yarn lint
# or
npm run lint
```


### Format the files
```bash
yarn format
# or
npm run format
```


### Build the app for production
```bash
quasar build
```
